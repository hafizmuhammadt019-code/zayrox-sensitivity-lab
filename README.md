# ZAYROX SENSITIVITY LAB

A premium, mobile-first Free Fire sensitivity generator and device optimization utility.
100% static — runs entirely on GitHub Pages with no backend required.

## What it does
- Analyzes a device (from a starter database or heuristic estimation)
- Generates a deterministic, weighted Free Fire sensitivity profile (DPI 480 default)
- Provides diagnostics for common aim/recoil issues
- Provides a Training/Calibration mode
- Provides a local-first AI assistant (LAB AI) with optional secure backend hook
- Saves/loads/exports/imports profiles via localStorage — no login required
